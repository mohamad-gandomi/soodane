# فرانت‌اند مدرن و ماژولار سودانه (Sodaneh Frontend)

فرانت‌اند مدرن، تمیز، موبایل‌محور و کاملاً فارسی فروشگاه آنلاین سودانه که با **Next.js 14 (App Router)**، **Tailwind CSS**، تایپ‌اسکریپت و کامپوننت‌های ماژولار الهام گرفته از **shadcn/ui** پیاده‌سازی شده است. این پروژه بر اساس طرح دیزاینر در پوشه `sample` و برای اتصال یکپارچه به بک‌اند `persian-ecommerce-boilerplate` بازنویسی و بازمهندسی شده است.

---

## ویژگی‌های کلیدی معماری (Clean Architecture)

- **حذف فایل‌های طویل و انباشته (Omit Long Files):** تمامی صفحات و کامپوننت‌های تک‌فایلی طویل طرح قبلی به کامپوننت‌های کوچک، خوانا و مستقل تفکیک شده‌اند.
- **کامپوننت‌های اتمیک و ماژولار:**
  - `src/components/ui/`: دکمه‌ها (`Button`)، نشان‌ها (`Badge`)، کارت‌ها (`Card`)، باتم شیت‌ها (`Sheet`)، اینپوت‌ها (`Input`)، تب‌ها (`Tabs`)، آکاردئون‌ها (`Accordion`) و آیکون‌ها (`Icon`).
  - `src/components/layout/`: شل اپلیکیشن با حداکثر عرض `430px` برای موبایل، بنر تبلیغاتی بالا، هدر استیکی و نوار ناوبری پایین (`BottomNav`).
  - `src/components/home/`: هدر خانه با انتخاب آدرس و سبد خرید، اسلایدر پیشنهادها، شبکه دسته‌بندی‌ها و پیشنهادهای شگفت‌انگیز.
  - `src/components/catalog/`: نوار فیلتر و مرتب‌سازی، شیت فیلتر پیشرفته چندانتخابی دسته‌بندی‌ها و بازه قیمت.
  - `src/components/product-detail/`: گالری تصاویر، کارت قیمت با درصد تخفیف، بنر پاداش خرید و معرف، ویژگی‌ها و نوار خرید پایین.
  - `src/components/cart/` و `src/components/checkout/`: اقلام سبد، خلاصه فاکتور و پاداش دریافتی، انتخاب شیوه ارسال، استفاده از پاداش کیف پول و درگاه پرداخت.
  - `src/components/rewards/` و `src/components/orders/`: کیف پول پاداش، تاریخچه تراکنش‌ها، لیست دوستان دعوت‌شده، کارت‌های سفارش و تایم‌لاین مراحل تحویل.
  - `src/components/auth/`: جریان ۴ مرحله‌ای احراز هویت با شماره موبایل و کد پیامکی (OTP).
- **لایه‌بندی خدمات و اتصال به بک‌اند:**
  - لایه `src/services/` به همراه `src/lib/api-client.ts` مستقیماً به اندپوینت‌های NestJS بک‌اند (`http://localhost:4000/api/v1`) متصل می‌شود.
  - دارای مکانیزم Fallback خودکار: در صورت خاموش بودن بک‌اند در زمان توسعه محلی، برنامه بدون کرش با داده‌های پیش‌فرض کار می‌کند.
- **طراحی مطابق نمونه دیزاینر:**
  - استفاده از متغیرهای رنگی اختصاصی برند سودانه (`--sn-green: #17815a` و ...).
  - اعداد و ارقام تماماً فارسی با فرمت تومان و جداکننده هزارگان.
  - پشتیبانی از PWA با `manifest.json` و ویوپورت بهینه موبایل.

## ساختار پوشه‌ها

```text
frontend/
├── public/
│   ├── assets/            # تصاویر کالاها و بنرهای تبلیغاتی
│   └── manifest.json      # مانیفست PWA
├── src/
│   ├── app/               # صفحات App Router
│   │   ├── page.tsx       # صفحه اصلی (خانه)
│   │   ├── special/       # فروش ویژه و شگفت‌انگیز با تایمر
│   │   ├── products/      # کاتالوگ، فیلتر و جزئیات کالا
│   │   ├── cart/          # سبد خرید
│   │   ├── checkout/      # تکمیل سفارش و پرداخت
│   │   ├── rewards/       # کیف پول پاداش و معرفی دوستان
│   │   ├── orders/        # پیگیری و جزئیات سفارش
│   │   ├── account/       # پروفایل، آدرس‌ها و خروج
│   │   ├── notifications/ # اعلان‌های سفارش و پاداش
│   │   ├── legal/         # قوانین و حریم خصوصی
│   │   ├── support/       # پرسش‌های متداول و ثبت تیکت
│   │   ├── auth/          # ورود و ثبت‌نام با OTP
│   │   └── landing/       # صفحه لندینگ معرف برند
│   ├── components/        # کامپوننت‌های ماژولار
│   ├── context/           # مدیریت استیت سبد خرید و حساب کاربری
│   ├── lib/               # توابع کمکی، تبدیل اعداد به فارسی و API Client
│   ├── services/          # سرویس‌های اتصال به REST API
│   └── types/             # تایپ‌های کامل TypeScript
├── .env.local             # متغیرهای محیطی
├── tailwind.config.ts     # پیکربندی استایل‌ها و رنگ‌های سودانه
└── package.json
```

## راه‌اندازی و اجرا

### ۱. نصب وابستگی‌ها
```bash
pnpm install
```

### ۲. اجرای محیط توسعه
```bash
pnpm dev
```
اپلیکیشن در آدرس [http://localhost:3000](http://localhost:3000) در دسترس خواهد بود.

### ۳. ساخت نسخه نهایی (Production Build)
```bash
pnpm build
pnpm start
```

## اتصال به بک‌اند

آدرس پایه API در فایل `.env.local` تعریف شده است:
```env
NEXT_PUBLIC_API_URL=http://localhost:4000/api/v1
```
سرویس‌های فرانت‌اند به‌طور مستقیم با ماژول‌های `auth`، `products`، `orders`، `wallet`، `referrals` و `users` بک‌اند `persian-ecommerce-boilerplate` هماهنگ هستند.
